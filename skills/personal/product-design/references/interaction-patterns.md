# 交互规则

## 十项设计原则

按具体问题检查相关原则。评审时指出用户在哪一步遇到问题，以及调整会怎样改善操作。

| 原则 | 设计判断 | 官方文档 |
| --- | --- | --- |
| 亲密性 | 让同一对象的字段、状态和操作彼此靠近，按信息关联强弱设置组内和组间距离。 | [亲密性](https://ant.design/docs/spec/proximity-cn/) |
| 对齐 | 给同类文案和字段稳定的阅读起点，供纵向比较的数值采用统一精度并右对齐。 | [对齐](https://ant.design/docs/spec/alignment-cn/) |
| 对比 | 用字号、字重、间距或语义色区分层级、主次与状态。重要状态同时用文字表达，需慎重决策的选项保持中立。 | [对比](https://ant.design/docs/spec/contrast-cn/) |
| 重复 | 复用有相同语义的布局、样式、术语和操作位置，让用户把一个页面学到的操作迁移到其他页面。 | [重复](https://ant.design/docs/spec/repetition-cn/) |
| 直截了当 | 简单且可控的编辑可在对象旁发起，明确可编辑区域、保存方式和取消结果。 | [直截了当](https://ant.design/docs/spec/direct-cn/) |
| 足不出户 | 优先在当前工作上下文内完成局部任务。根据信息量和操作复杂度选择行内展开、浮层、抽屉或独立页。 | [足不出户](https://ant.design/docs/spec/stay-cn/) |
| 简化交互 | 将高频操作放在对象附近，低频操作按需出现。保证关键操作在键盘和触屏场景可发现、可执行。 | [简化交互](https://ant.design/docs/spec/lightweight-cn/) |
| 提供邀请 | 用可见入口、示例、空状态引导或操作前提示，让用户知道可以做什么。按需提供可退出的引导。 | [提供邀请](https://ant.design/docs/spec/invitation-cn/) |
| 巧用过渡 | 视图切换时保留对象与位置线索，用必要的过渡说明内容从哪里来、刚发生了什么。 | [巧用过渡](https://ant.design/docs/spec/transition-cn/) |
| 即时反应 | 接收操作时及时响应，按场景提供输入校验、预览、处理中状态和最终结果，反馈强度与操作影响相称。 | [即时反应](https://ant.design/docs/spec/reaction-cn/) |

## 全局规则

### 导航

- 先按用户任务梳理层级，再选择全局菜单、页内导航、下钻与返回方式。横向菜单适合入口少且结构浅的产品，侧栏适合多模块后台。全局搜索、帮助和消息放在全局位置，页面级操作留在页面内。
- 面包屑用于交代父子层级，页签切换同级内容，步骤条表达有先后顺序的任务。检查用户从外部链接进入详情时能否识别位置，从详情返回时能否继续原来的工作。 [导航](https://ant.design/docs/spec/navigation-cn/) · [探索导航](https://ant.design/docs/spec/research-navigation-cn/)

### 数据录入

- 根据输入类型和候选范围选择控件。候选少且需要一眼比较时平铺选项，候选多时用可搜索的选择控件。开关表达即时生效，依赖统一提交的设置应明确生效时机。
- 明确字段标签、必填、默认值、格式、联动和校验时机。上传前说明格式、大小和数量限制，上传中展示进度，失败后提供重试或替换。 [数据录入](https://ant.design/docs/spec/data-entry-cn/)

### 数据展示与格式

- 按阅读任务选结构。结构化横纵比较用表格，独立对象概览可用卡片，层级数据用树，操作历史用时间轴，次要分组信息可折叠。
- 统一数字精度、千分位、单位、币种、时间格式和空值标记。审计记录优先用可准确追溯的时间，强调消息时效时可用相对时间。明确敏感字段的可见范围与脱敏方式，区分数值零、缺失、加载中和受限。 [数据展示](https://ant.design/docs/spec/data-display-cn/) · [数据格式](https://ant.design/docs/spec/data-format-cn/)

### 按钮与文案

- 同一操作区优先突出一个主操作，用间距或布局区分操作组。低频操作可收入更多菜单。纯图标按钮给出可访问名称，并提供可感知的含义提示。
- 采用用户熟悉的术语，按钮用具体动作命名。危险操作的确认文案写明对象、影响范围和能否撤销。错误提示先交代发生了什么，再给出可执行的解决方式。 [按钮](https://ant.design/docs/spec/buttons-cn/) · [文案](https://ant.design/docs/spec/copywriting-cn/)

### 数据列表

- 区分提交一组条件的查询、改变条件即更新的筛选，以及按关键词匹配的搜索。说明筛选、排序、分页的默认值和相互影响，从详情返回时恢复必要的列表上下文。
- 选中后显示批量操作及作用范围，明确跨页选择是否可用。耗时批量操作按需提供进度、逐项结果和重试范围。删除类操作按影响和可逆性选择直接操作、确认或额外校验。 [数据列表](https://ant.design/docs/spec/data-list-cn/)

### 反馈

- 用户能立即从界面看到结果时，直接更新原处。字段错误就近提示并保留可编辑输入，持续有效的提醒放在相关区域，简短低风险结果可用轻提示。
- 根据反馈范围和紧急程度选择通知、对话框或结果页。后台操作可通过通知或任务入口查询结果。加载提示与影响范围匹配，可取消或重试时提供相应动作。 [反馈](https://ant.design/docs/spec/feedback-cn/) · [探索消息与反馈](https://ant.design/docs/spec/research-message-and-feedback-cn/)
