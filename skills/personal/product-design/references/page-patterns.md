# 页面模式

按用户当前要完成的任务选模式，再按信息量、上下文依赖和操作复杂度确定容器。列表中少量补充信息可行内展开，快速查看或轻量编辑可用抽屉，频繁切换对象可用双栏，需单独分享或专注处理的任务适合独立页。 [数据列表](https://ant.design/docs/spec/data-list-cn/) · [足不出户](https://ant.design/docs/spec/stay-cn/)

## 工作台

按角色和使用频率安排待办、常用入口和需要关注的指标，首屏优先放用户当下需要处理的事项。给已有用户直达常用任务的入口，首次使用时提供可执行的起步动作。区分「待办已处理完」和「还未建立任务」等状态。 [工作台](https://ant.design/docs/spec/research-workbench-cn/)

## 列表页

需要精确查找和多字段比较时用查询表格，快速浏览条目摘要时用标准列表，突出对象自身内容时用卡片列表。筛选条件多且横向空间充足时考虑侧栏筛选。说明怎样进入详情，以及返回后保留的筛选、排序、页码、选择或滚动位置。 [列表页](https://ant.design/docs/spec/research-list-cn/) · [数据列表](https://ant.design/docs/spec/data-list-cn/)

## 详情页

先给出对象标识、当前状态和当前角色可执行的操作，再按信息关联程度选择同卡分组、分区或页签。审批单据优先让用户看清待办、处理依据和历史记录。按角色与状态写清可见信息、操作条件、执行结果及下一处理人。 [详情页](https://ant.design/docs/spec/detail-page-cn/)

## 表单页

少量字段可单列平铺。字段多且能按主题组织时采用分组，有明确先后依赖时采用分步，并说明回退修改和最终提交行为。设置页明确即时生效或统一提交。交付时标明字段默认值、必填、联动、校验、提交中行为，以及提交失败后保留哪些输入。 [表单页](https://ant.design/docs/spec/research-form-cn/) · [数据录入](https://ant.design/docs/spec/data-entry-cn/)

## 结果页

长流程结束、结果需解释或需提供凭证时，可用独立结果页。标题说明对象、动作和结果，按需补充原因或摘要，突出最可能的后续操作。异步提交区分已受理、处理中与最终完成，给出查看结果的入口。轻量操作优先在原处反馈。 [结果页](https://ant.design/docs/spec/research-result-cn/) · [反馈](https://ant.design/docs/spec/feedback-cn/)

## 异常与空状态

先判断问题影响单元格、模块还是整页，局部异常保留可用内容。按真实原因给出下一步。

| 场景 | 呈现与恢复 |
| --- | --- |
| 首次无数据 | 说明功能用途，提供与当前权限匹配的创建、导入或了解入口。 |
| 筛选无结果 | 保留当前条件，提供清除或修改条件的操作。 |
| 已全部处理 | 告知当前工作已清空，按需提供查看历史的入口。 |
| 加载失败 | 说明受影响范围，可重试时提供入口，保留现有上下文。 |
| 无权限、资源不存在或服务异常 | 分别给出申请权限、返回可用入口或重试等当前场景可行的动作。 |

参考 [异常页](https://ant.design/docs/spec/research-exception-cn/) · [空状态](https://ant.design/docs/spec/research-empty-cn/)。

## 数据可视化页

先确定用户要监控、分析还是查明细。监控页突出关键指标与异常，分析页围绕主题组织对比和筛选，明细页支持定位原始数据。按概览、聚焦、下钻组织路径，并说明图表筛选的联动范围。图表选择和标注查阅[全局样式与专题](visual-guidelines.md#可视化)。 [数据可视化页](https://ant.design/docs/spec/visualization-page-cn/)
