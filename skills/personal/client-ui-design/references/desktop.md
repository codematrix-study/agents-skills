## 1. 窗口与标题栏

- 默认尺寸 1200×800,最小 900×600;记住上次尺寸与位置。
- 自绘标题栏必须保留系统行为:可拖拽、双击最大化、窗口控件位置符合平台(mac 左上红绿灯,Win 右上)。标题栏高 38~44px。
- 拖拽区(`-webkit-app-region: drag`)与可点击控件(`no-drag`)严格区分,按钮、输入框一定设为 `no-drag`。
- **窗口失焦态**:失焦时标题栏与侧栏降低对比度/透明度,是原生感最明显的细节之一。
- mac:侧栏可用 vibrancy 半透明;Win11:可用 Mica。降级方案是 `--surface-0` 纯色。

## 2. 应用外壳(AppShell)

典型三栏结构,宽度建议:

```
| 侧栏 240~280 (可拖拽 200~360, 可折叠至 56) | 主内容 flex | 可选右侧面板 320~400 |
```

- 先做壳:标题栏 + 侧栏 + 主区 + 状态栏/全局指示,所有页面复用,不每页重做。
- 侧栏与主区靠**表面明度差**分隔(`--surface-0` vs `--surface-1`),分隔线用 `--separator` 1px。
- 右侧面板(详情、预览、任务)可开合,开合动画 200ms,主区宽度自适应不跳动。
- 窗口缩小时的响应:< 1000px 自动折叠侧栏为图标;< 800px 右侧面板改为覆盖层。

## 3. 侧边栏与导航

- 结构:顶部(Logo/工作区切换 + 新建)→ 主导航(≤ 7 项)→ 动态列表(历史/项目,可滚动)→ 底部(设置、账号、更新提示)。
- 项高 32~36px,图标 16~18px,选中态用 `--surface-selected` + 品牌色文字/图标,圆角 6px,**不用左侧竖条与整块深色并存**。
- 分组标题 11~12px、灰色、不可点;分组可折叠,折叠状态记忆。
- 列表项 hover 时才显示次要操作(重命名/删除/更多),避免常驻图标堆叠。
- 未读/进行中用 6~8px 小圆点或细进度环,不用大徽标。
- 折叠为图标态时,tooltip 在 300ms 延迟后出现。

## 4. 主内容区与布局

- 内容最大宽度:阅读/对话 720~840px 居中;表格/看板可全宽。
- 页面头部:标题(18px/600)+ 次要信息 + 右侧操作,高度固定 48~56px;滚动时头部吸顶并出现 1px 分隔线。
- 卡片非必须:桌面客户端多用"分组列表 + 分隔线",比到处卡片更清爽。必须用卡片时统一圆角 8px、1px 半透明边框、无阴影。
- 内容区内边距 24px(紧凑 16px)。

## 5. 对话 / 工作流类界面

(适用于 AI 助手、办公 Agent 等产品)

- **布局**:消息流居中 720~800px;输入框固定底部、悬浮于内容之上(带轻微阴影与 `--surface-2`),高度自适应 1~8 行,超出内部滚动。
- **消息样式**:用户消息右对齐浅底气泡(或品牌浅底);助手消息无气泡、左对齐,靠留白与字号层级区分,长内容更易读。
- **输入框**:`Enter` 发送、`Shift+Enter` 换行;**IME 组合输入期间 Enter 不发送**(监听 `isComposing`);支持粘贴图片/文件、拖拽、`/` 命令、`@` 引用。
- **流式输出**:光标/打字机仅作轻提示;滚动策略——用户未上滑时自动跟随,上滑则暂停并出现"回到底部"按钮。
- **工具调用与任务步骤**:折叠为一行摘要(图标 + 动作 + 状态),可展开看详情;进行中用细进度或脉冲点,完成后变为静态勾。步骤状态:等待 / 进行中 / 成功 / 失败 / 已跳过。
- **产物(文件、图表、文档)**:以卡片形式嵌入消息或在右侧面板预览;卡片含文件类型图标、名称、大小、"打开/保存"操作。
- **长任务**:顶部或侧栏显示任务条(进度 + 可取消),支持后台继续;完成用系统通知。
- **失败态**:说明原因 + "重试 / 换个方式",保留已产出内容,不整条消息红色。
- **用量与额度**:余额/积分放账号区或输入框旁的弱提示,接近阈值时才升为警告,不占据主视觉。
- **空状态**:欢迎语 + 3~4 个示例任务卡片(点击即填入输入框),比空白与长教程有效。

## 6. 列表、表格与设置页

- 列表行 32~40px,hover 底色 `--surface-hover`,选中 `--surface-selected`,支持键盘上下/回车/Delete。
- 数据表格(如任务记录):数字右对齐 tabular-nums、无值 `—`、行高统一、表头吸顶;右键菜单提供行操作。
- 设置页:左侧分组(通用/外观/账号/高级/关于),右侧单列表单;每项 = 标题 + 说明 + 右侧控件,行间用分隔线。开关即时生效,不需要"保存"按钮;需重启的项明确标注。
- 外观设置必含:主题(跟随系统/浅/深)、字号、密度、语言。

## 7. 菜单、快捷键、右键

- 提供系统菜单栏(mac 顶部,Win 窗口菜单或汉堡菜单),常用命令都能在菜单找到。
- 通用快捷键(mac `⌘` / Win `Ctrl`):新建 N、搜索 K(命令面板)、设置 `,`、关闭窗口 W、撤销/重做、复制粘贴、切换侧栏 `\`。
- 命令面板(`⌘K`):模糊搜索页面与操作,是高效率用户的核心入口。
- 右键菜单:项 ≤ 8,分组用分隔线,危险项在最后且为红色;图标可选,统一线性。
- 快捷键提示显示在菜单项与 tooltip 右侧,灰色小字。

## 8. 全局状态与通知

固定位置的轻量指示(底部状态栏或侧栏底部):
- 同步:同步中(旋转图标)/ 已同步 / 同步失败(可点重试)
- 网络:离线时顶部出现 32px 细条 "当前离线,部分功能不可用",恢复后自动消失
- 更新:侧栏底部"有新版本"小条,可稍后;强制更新用阻断弹窗并说明原因
- 登录过期:弹出重新登录,保留未发送的输入内容

通知:Toast 4~6s 自动消失,可撤销操作带 "撤销" 按钮;重要结果用系统通知;同类通知合并,不连环弹出。

## 9. 多窗口与浮层

- 浮层层级固定:Tooltip < 下拉/菜单 < 抽屉 < 弹窗 < Toast;统一 z-index 表。
- 弹窗宽度 400/560/720 三档;标题 + 说明 + 操作区,主按钮在右;`Esc` 关闭、`Enter` 确认、焦点陷阱与回焦。
- 抽屉(右侧)用于详情/编辑,优先于弹窗,避免丢失上下文。
- 多窗口(设置、悬浮助手)与主窗口共用 tokens 和主题状态。

## 10. 性能与"跟手感"

- 点击到视觉反馈 < 100ms;列表 > 200 项用虚拟滚动;大图/文档预览懒加载。
- 乐观更新:发送消息、重命名、置顶先改 UI,失败再回滚并提示。
- 骨架屏替代整页 loading;局部更新不闪烁、不重置滚动位置与选中项。
- 避免布局抖动:图片/卡片预留尺寸;字体用系统字体免加载。
- 动画用 `transform/opacity`,避免触发大范围重排;低性能设备降级动效。

- [ ] 快捷键与命令面板、右键菜单可用
- [ ] 同步/离线/更新/登录过期状态有固定指示
