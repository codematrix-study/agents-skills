## 1. 屏幕与安全区

- 设计基准:iOS 390×844 pt、Android 360×800 dp;需适配 320~430 宽、折叠屏与平板(平板用双栏)。
- 必须处理安全区:顶部状态栏/刘海/灵动岛、底部 Home Indicator/手势条;固定底栏与浮动按钮加 `safe-area-inset-bottom`。
- 键盘弹出时输入区上推且不遮挡;表单自动滚动到焦点字段。
- 横屏:内容页可旋转,其余可锁竖屏,但要有明确决策。

## 2. 导航结构

- 主导航:**底部 Tab 3~5 项**(图标 + 文字,选中态品牌色),只放一级功能;不要把"设置"当 Tab。
- 二级页面:顶部导航栏(返回 + 标题 + ≤ 2 个操作);iOS 支持左边缘右滑返回,Android 响应系统返回。
- 层级 ≤ 3 层;深层任务用全屏模态(底部上滑)并有明确的"关闭/完成"。
- 浮动主操作(FAB/发送/新建)每页最多 1 个,位于拇指热区(屏幕下半部、右手侧)。
- 首页回答"现在最重要的事":待办、进行中任务、快捷入口,而不是功能菜单大全。

## 3. 布局、间距与字号

- 页面左右边距 16pt(紧凑 12);卡片间距 12;分组间距 24。
- 字号:正文 16、次要 14、说明 12、标题 20~22、大标题 28~34。不低于 12。
- 行高 1.4~1.6;列表项高 ≥ 56pt(单行 48);卡片圆角 12~16。
- 单手可达:关键操作放底部;顶部只放导航与次要操作。
- 内容区纵向滚动为主,避免嵌套滚动与横向滚动抢手势。

## 4. 触控与手势

- 触控目标 ≥ 44×44 pt(iOS)/ 48×48 dp(Android),相邻目标间距 ≥ 8。
- 所有可点元素有按压态(背景变深 / 水波纹 / 缩放 0.97),延迟 < 100ms。
- 手势要有可见替代:左滑删除同时可在详情页或长按菜单中找到。
- 下拉刷新、上拉加载、左滑返回不冲突;横向轮播与侧滑返回边缘留出安全距离。
- 长按 = 次级操作(预览、多选、菜单),不要承载唯一入口。

## 5. 组件规范

- **按钮**:主按钮高 48~52,圆角 12 或 pill,全宽或底部固定;次按钮描边/文字;禁用态降低对比并说明原因。
- **输入框**:高 48,label 在上或浮动,清除按钮、密码显隐、聚焦边框品牌色。
- **卡片**:白/表面色 + 轻阴影或 1px 描边,内边距 16;可点卡片整体可点,右侧箭头指示。
- **底部弹层(Bottom Sheet)**:替代居中弹窗承载选择、筛选、操作列表;顶部拖拽条;可下拉关闭。
- **对话框**:仅用于需要阻断的确认,≤ 2 个按钮,危险操作按钮红色。
- **Toast/Snackbar**:底部、2~4s、可带撤销。
- **标签/角标**:未读用 8px 红点,数字角标 ≤ 99+。
- **图标**:线性或填充(选中态填充)统一风格,24pt。

## 6. 列表、表单与输入

- 列表:骨架屏 → 内容;下拉刷新;分页加载有底部状态("加载中 / 没有更多了");空态含插画/说明/主操作。
- 左滑操作 ≤ 2 个,颜色语义清晰(删除红色)。
- 表单:单列、字段分组、一屏一个主任务;长表单分步并显示进度;自动填充、合适的键盘类型(`numeric`、`email`)。
- 选择器优先用系统原生/底部弹层,少用小下拉。
- 对话输入:底部固定输入栏,随键盘上移;多行自适应;发送按钮仅在有内容时激活;支持语音与附件入口(+ 号展开)。
- 提交后立即反馈(按钮 loading),并防重复点击。

## 7. 反馈、状态与权限

- 状态齐全:加载 / 空 / 错误 / 无网络 / 权限被拒 / 首次使用。
- 网络异常:页面顶部细条或占位页带"重试";弱网下保留已加载内容。
- 权限(通知、相机、相册、定位):**在需要的时刻请求**,先用说明页解释用途再触发系统弹窗;被拒后给出"去设置开启"引导。
- 触觉反馈(Haptics)用于关键确认(成功、选择、危险),不滥用。
- 推送:合并同类、可关闭分类、点击直达对应内容页。
- 余额/额度类:用进度条 + 剩余量,接近阈值才升为警告并给入口。

## 8. 主题、字体缩放与国际化

- 亮/暗主题跟随系统;图片与插画适配暗色。
- 支持系统字体放大(Dynamic Type / 字体缩放至 200%):布局用弹性高度、允许换行,不写死行高;关键布局在最大字号下测试。
- 文案预留 +30% 长度;日期、数字、货币按区域格式化;RTL 视需求预留。
- 对比度 ≥ 4.5:1;不只用颜色表达状态;为图标按钮提供无障碍标签(VoiceOver/TalkBack)。

## 9. 平台差异

| 项 | iOS | Android |
|---|---|---|
| 导航栏标题 | 居中/大标题折叠 | 靠左 |
| 返回 | 左上箭头 + 边缘滑动 | 系统返回 + 顶部箭头 |
| 选择弹层 | ActionSheet / Picker | Bottom Sheet / Dialog |
| 开关/日期等控件 | 系统风格 | Material 风格 |
| 反馈 | 缩放/高亮 | 水波纹 |
| 提示 | Alert / Toast(自定义) | Snackbar |

跨端框架(Flutter/RN)策略:统一 tokens 与品牌视觉,**导航手势、系统弹层、返回行为遵循各平台**;不要强行让两端像素级一致。小程序遵循宿主(微信/支付宝)的导航与组件规范,避免自造导航栏。

- [ ] 触控目标达标,按压态齐全
- [ ] 主操作在拇指热区,每页 ≤ 1 个主 CTA
- [ ] 加载/空/错误/无网/权限被拒 状态齐全
- [ ] 字体放大 200% 与长文案不破版
- [ ] 亮/暗主题、图片适配
- [ ] 手势有可见替代,且无冲突
- [ ] 权限在使用时机请求并有说明
- [ ] 无障碍标签与对比度达标
