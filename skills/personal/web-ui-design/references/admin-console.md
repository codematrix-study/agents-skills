# 管理端 / 运营后台设计指南

管理端用户是"每天高频使用的专业人员"。设计目标:**信息密度适中、扫读效率高、操作零歧义、长时间看不累**。不追求惊艳,追求稳。

## 1. 整体框架

- 顶栏高 56px;侧边栏宽 220~240px(可折叠至 64px);内容区最大宽度 1440px,居中或左对齐。
- 页面头部:标题(28px/600)+ 右侧主操作/时间切换;副信息(日期范围、统计截至时间)用 13px 灰色一行小字,**不要做成整宽描边盒子**。
- 内容区背景用 `--bg-page`,内容放在 `--bg-surface` 卡片中,卡片间距 16~24px。
- 一页一个主操作按钮(品牌色实心),其余用描边/文字按钮。

## 2. 数据面板(Dashboard)

信息层级金字塔,自上而下:

1. **核心指标(Today/Period KPI)**:3~4 个,等宽卡片。回答"业务正常吗"。
2. **趋势 + 异常/待办**:左 2/3 趋势图,右 1/3 待处理事项。回答"哪里变了、要处理什么"。
3. **明细/分解**:按维度拆解的表格或条形图。回答"为什么"。
4. **存量/资产类指标**(累计、余额):**视觉上弱于第 1 层**,字号小一档,可并入"概览"卡片。

KPI 卡片规范:
- 结构:标题(13px 灰)→ 数值(28~32px/600,tabular-nums)+ 单位(13px 灰,基线对齐)→ 可选一行辅助(对比上期 ▲▼ 或口径说明,12px 灰)。
- 同一行所有卡片高度一致、字号一致。数据为 0 也不放大。
- 对比上期用语义色(涨绿跌红要按业务含义判断,成本上涨应为红),且必须带箭头或文字,不只靠颜色。
- 口径说明(如"按账号去重")放卡片底部 12px,或 tooltip。

异常/待办卡片:
- 总数徽标用红色;分类列表 = 色点 + 名称 + 数量(右对齐)。**分类数量之和必须等于总数**,差额显示为"其他/未归因"。
- 底部只保留 1 个主入口("查看全部"),其余用 tooltip 或行内 hover 链接。
- 为 0 的待办压缩成单行空状态("暂无待复核 ✓"),不占整块。
- 不要在卡片内再嵌灰色子卡片;用 1px 分隔线 + 间距即可。

## 3. 图表规则

- 一个图表只展示**同一单位**的指标。次数、人数、金额要切换时,Tab 切换并在图表左上角写明当前单位。
- X 轴刻度完整且均匀:7 天就 7 个刻度,不跳号;30 天可每 5 天一个。
- **未结束的当天/当期**:数据点用虚线连接 + 空心点 + "统计中"提示,避免被误读为"暴跌到 0"。
- 网格线极淡(`--border` 的 60% 透明度),去掉垂直网格;主线 2px,数据点仅在 hover/末点显示。
- 色板:第 1 色品牌色,其余按中性蓝灰递进;最多 6 色;对比两组数据用"实线 vs 虚线"补充区分。
- 图表卡片高度由内容决定,**不要为了和邻卡等高而留大块空白**;空间有余时补一排迷你汇总(峰值、均值、较上期)。
- Tooltip 展示完整日期 + 数值 + 单位,数字格式与页面一致。
- 空数据:显示"所选时间内暂无数据"并保留坐标框架,不显示空白。

## 4. 表格

- 行高:紧凑 40px / 默认 48px / 宽松 56px;**同一表格行高必须一致**——不要把"数值 + 标签"上下堆叠撑高某些行,标签放同行右侧或用圆点 + tooltip。
- 表头:`--bg-subtle` 底,13px/500,灰色文字;支持排序时用表头图标,不要在角落写"按××排序"。
- 对齐:文本左对齐;数字、金额、百分比**右对齐 + tabular-nums**;状态/操作居中或左对齐。
- 列宽:先给文本列 `min-width`,数字列固定宽度;避免数字列之间出现巨大空隙(可限制表格最大宽度或拉大文本列)。
- 无值统一显示 `—`(灰色),不要留空、不要写 0 或 N/A 混用,且 `—` 不再配警告标签。
- 业务名称列:默认深色文字;仅可点时 hover 变品牌色 + 出现箭头,避免整列蓝色"链接海"。
- 行操作:主操作 1 个文字按钮,其余收进 `⋯` 菜单;危险操作用红色并二次确认。
- 批量选择:选中后出现顶部操作条,显示"已选 N 项"。
- 分页:靠右,含总数与每页条数;超 1 万行考虑游标分页或虚拟滚动。
- 空/加载/错误:空态给原因与操作;加载用骨架行;错误给重试。
- 固定表头与首列(横向滚动时),窄屏表格在容器内横向滚动,不撑破页面。

## 5. 筛选与搜索

- 常用筛选直接露出(≤ 4 个),其余收进"更多筛选"。
- 已应用的筛选以 chip 展示,可单个移除,并提供"重置"。
- 搜索框 240~320px,placeholder 写明可搜内容;支持回车与清除。
- 时间范围:快捷项(今日/7日/30日)+ 自定义;分段控件选中态用白底 + 轻阴影,而不是整块品牌色。

## 6. 表单

- 单列布局为默认;label 放输入框上方,13px/500;必填标 `*`,非必填不标"选填"噪音。
- 分组:用小标题 + 分隔线,每组 ≤ 6 个字段;长表单用分步或锚点导航。
- 校验:失焦时校验,错误文字在字段下方,红色 + 图标;提交时滚动到第一个错误。
- 辅助说明 12px 灰,放在输入框下;不要把说明塞进 placeholder。
- 输入框高 36px(紧凑 32px),圆角 6~8px,focus 用 `--focus-ring`。
- 底部操作栏:主按钮在右,取消在其左;保存中禁用并显示 loading。

## 7. 状态标签与反馈

- 标签(Tag)高 22~24px,12px 字,浅底 + 深字(`*-bg` + `*-fg`),不用实心深色块。
- 状态集合要有限且互斥:成功 / 进行中 / 待处理 / 警告 / 失败 / 已停用 → 各一种颜色。
- 提示分级:Toast(轻量、自动消失)/ Inline Alert(页面级、需关注)/ Modal(阻断式、仅危险操作)。
- **同类警告全页只出现 1~2 处**,其余降级为圆点 + tooltip,否则会被用户忽略。

## 8. 危险操作与权限

- 删除/禁用/重置:红色文字按钮 → 确认弹窗,标题写明对象与后果,确认按钮文案用动词("删除用户"),不用"确定"。
- 不可逆操作要求输入对象名确认。
- 无权限:隐藏次要入口、禁用并给 tooltip 原因,而不是点击后才报错。

## 9. 侧边栏与导航

- 一级分组标题 12px 灰色大写/小字;菜单项 40px 高、14px;选中态 = 浅品牌底 + 左侧 3px 竖条或品牌色文字,二选一。
- 分组数 ≤ 7,每组项数 ≤ 7;分组标题**不得重复**(重复标题或被截断的项通常是渲染/数据 bug,应排查而非美化)。
- 图标统一线性风格、同一粗细(1.5px)与尺寸(16/18px)。
- 当前位置面包屑放在页头标题上方。

## 10. 管理端自检清单

- [ ] KPI 区层级:核心指标 > 趋势/异常 > 明细;存量指标弱于核心指标
- [ ] 全页容器语言一致,卡片标题位置统一
- [ ] 数字格式统一,右对齐,无拆分字号
- [ ] 图表单位明确、刻度完整、未结束数据已标识
- [ ] 异常分类之和 = 总数
- [ ] 表格行高一致,无值统一 `—`,警告不重复
- [ ] 链接层级清晰,主链接每卡 ≤ 1
- [ ] 空/加载/错误态齐全
- [ ] 危险操作有二次确认
- [ ] 侧边栏无重复/截断标题
